# Перенос Arch ↔ Windows

Этот репозиторий создаёт два воспроизводимых сценария:

- **Arch → Windows** — устанавливает доступные Windows-версии приложений через `winget` и, по желанию, переносит совместимые настройки.
- **возврат на Arch** — устанавливает весь текущий список явно установленных пакетов (официальные репозитории, AUR и Flatpak) и восстанавливает сохранённые настройки, включая Caelestia.

Caelestia сохраняется для Arch, но не ставится на обычную Windows: это Linux/Wayland-оболочка на базе Quickshell и Hyprland. Официальная инструкция для Arch: [caelestia-dots/shell](https://github.com/caelestia-dots/shell#arch-linux).

## Что уже зафиксировано

- 196 явно установленных пакетов Arch, 46 AUR-пакетов и 5 Flatpak-приложений;
- Caelestia (`caelestia-shell`) и её настройки из `~/.config/caelestia`;
- установщики для Windows и нового Arch;
- список пакетов Node.js.

## 1. Сохранить настройки на текущем Arch

Сначала закройте браузеры, Discord/Vesktop, редакторы и другие приложения — так архив будет консистентнее. Затем из корня репозитория запустите:

```bash
./scripts/capture-arch-state.sh
```

Скрипт обновит списки программ и создаст **зашифрованный паролем** файл в `archive/`. Скопируйте этот файл на внешний диск или в защищённое облако. Он намеренно игнорируется Git и не будет опубликован.

В архив не включаются пароли, cookies, токены, активные сеансы, keyring, кэши и логи. В приложениях после переноса нужно будет войти в аккаунты заново.

## 2. Установить Windows-программы

Скопируйте репозиторий и зашифрованный архив на новый ПК. Откройте PowerShell и из корня репозитория выполните одну команду:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force; .\windows\Install-Windows.ps1
```

`winget` установит Windows-версии доступных приложений. Если в `archive/` лежит ровно один зашифрованный архив, скрипт предложит пароль к нему и применит только совместимые настройки: VS Code, Windsurf, Obsidian, qBittorrent, LibreOffice, GIMP, Git, GitHub Desktop, Vesktop и Zed.

Профили браузеров не копируются: Windows шифрует сохранённые пароли ключом другой ОС. Для Chrome, Firefox, Brave, Zen и Yandex Browser используйте штатную синхронизацию аккаунта.

## 3. Полностью восстановить Arch позже

На свежем Arch склонируйте этот репозиторий, положите зашифрованный архив в `archive/` и выполните:

```bash
./scripts/setup-arch.sh
```

Сценарий автоматически ставит `yay`, официальные пакеты, AUR-пакеты и Flatpak-приложения. Если архив лежит в `archive/`, он расшифруется и восстановит настройки с резервной копией уже существующих файлов в `~/.migration-backups/`.

## Что нельзя перенести автоматически на Windows

Hyprland, Quickshell, Caelestia, Wayland-панели, PipeWire/EasyEffects, Linux-драйверы, Wine/Proton, systemd и настройки оконного менеджера относятся к Linux. Они сохраняются внутри архива и восстановятся при возвращении на Arch. Для Windows установщик ставит только нативные или кроссплатформенные аналоги.

## Публикация на GitHub

Репозиторий готов к публикации; `archive/` надёжно исключён из Git. Перед публикацией нужно заново войти в GitHub CLI: текущий токен компьютера недействителен. После `gh auth login` выполните:

```bash
./scripts/publish-github.sh
```

Используйте приватный репозиторий: даже очищенные настройки могут содержать персональные данные, например закладки браузера или пути к файлам.
